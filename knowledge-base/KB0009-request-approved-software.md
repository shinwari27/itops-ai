# KB0009: Request approved software

Approved apps install automatically after you request them.

## How it works
1. Open **Software** in this portal.
2. Select **Request** on the app you need.
3. Free apps install within about 15 minutes. Licensed apps need your manager's approval first.

Need an app that isn't listed? Submit a ticket and describe what you need it for.
