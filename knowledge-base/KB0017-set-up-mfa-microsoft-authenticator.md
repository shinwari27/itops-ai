# KB0017: Set up MFA (Microsoft Authenticator)

Multi-factor authentication (MFA) protects your account even if someone learns your password.

## Steps
1. Install **Microsoft Authenticator** on your phone.
2. On a computer, go to **aka.ms/mysecurityinfo** and sign in.
3. Click **Add sign-in method → Authenticator app**.
4. Scan the QR code with the app.
5. Approve the test notification.

## New phone?
Sign in to aka.ms/mysecurityinfo and add the new phone before wiping the old one. If you already lost the old phone, submit a ticket so the Help Desk can reset your MFA.
