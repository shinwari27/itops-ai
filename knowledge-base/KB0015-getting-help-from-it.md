# KB0015: Getting help from IT

## Fastest way to get help
1. Search this knowledge base first.
2. Submit a ticket describing what happened, when, and any error message.
3. Add a screenshot if you can.

## Response targets
- **P1 Critical:** 15 minutes
- **P2 High:** 1 hour
- **P3 Medium:** 4 hours
- **P4 Low:** 1 business day
