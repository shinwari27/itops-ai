# KB0010: Wi-Fi drops during calls

## Things that help
- Sit closer to an access point or use the docking station's cable.
- Turn off Bluetooth devices you aren't using.
- Restart your laptop.

If calls keep dropping in one area of the office, tell us which room so Network Support can check coverage.
