# KB0022: Laptop running Windows updates

Company laptops install security updates automatically.

## Best practice
- Restart your laptop at least once a week.
- Do not power off while it says "Working on updates".

## Update stuck or failing?
1. Go to **Settings → Windows Update → Check for updates**.
2. Restart and try again.
3. If you see the same error twice, submit a ticket with the error code (for example 0x80070002).
